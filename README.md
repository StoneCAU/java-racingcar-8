# 자동차 경주 게임

## 프로젝트 개요
무작위로 전진하는 자동차들의 경주를 시뮬레이션하고 우승자를 판별하는 콘솔 기반 게임

### 주요 기능
- 여러 대의 자동차가 동시에 경주
- 무작위 값(0~9)에 따른 전진 여부 결정
- 라운드별 경주 진행 상황 출력
- 최종 우승자(최장 거리 이동 차량) 판별

### 실행 예시
```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun

시도할 횟수는 몇 회인가요?
5

실행 결과
pobi : -
woni :
jun : -

pobi : --
woni : -
jun : --

pobi : ---
woni : --
jun : ---

pobi : ----
woni : ---
jun : ----

pobi : -----
woni : ----
jun : -----

최종 우승자 : pobi, jun
```

---

## 기능 요구 사항
- 자동차 이름은 쉼표(`,`)로 구분하며 5자 이하
- 각 자동차는 0~9 사이 무작위 값에 따라 전진 (4 이상이면 전진)
- 라운드마다 각 자동차의 위치를 `-`로 표시
- 최장 거리를 이동한 자동차가 우승 (공동 우승 가능)

---

## 구현 기능 목록

### ✅ 입력
- [x] 자동차 이름 입력 받기 (쉼표 구분)
- [x] 시도 횟수 입력 받기

### ✅ 자동차 이름 검증
**입력 형식 검증**
- [x] 빈 문자열 입력 불가
- [x] 쉼표로 파싱하여 자동차 이름 리스트 생성

**개별 자동차 이름 검증**
- [x] 이름은 5자 이하
- [x] 빈 이름 불가
- [x] 중복된 이름 불가
- [x] 최소 1대 이상의 자동차 필요

### ✅ 시도 횟수 검증
- [x] 빈 문자열 입력 불가
- [x] 숫자 형식 검증
- [x] 1 이상의 양수만 허용

### ✅ 경주 진행
**전진 로직**
- [x] 0~9 사이의 무작위 값 생성
- [x] 4 이상이면 전진, 3 이하면 정지
- [x] 각 자동차마다 독립적으로 판단

**라운드 진행**
- [x] 지정된 횟수만큼 라운드 반복
- [x] 각 라운드마다 모든 자동차 이동 시도
- [x] 매 라운드 결과 출력

### ✅ 출력
**진행 상황 출력**
- [x] "실행 결과" 헤더 출력
- [x] 각 자동차의 이름과 위치 출력 (`이름 : ---`)
- [x] 위치는 `-` 문자로 표시
- [x] 라운드 사이 빈 줄 출력

**우승자 발표**
- [x] 최장 거리 계산
- [x] 최장 거리 자동차 찾기
- [x] 공동 우승자 쉼표로 구분하여 출력
- [x] "최종 우승자 : {이름}" 형식

### ⚠️ 예외 처리
다음의 경우 `IllegalArgumentException` 발생

| 예외 상황 | 예시 입력 |
|---------|----------|
| 자동차 이름 없음 | `""`, `null` |
| 자동차 이름 5자 초과 | `"pobi,javaji"` |
| 중복된 이름 | `"pobi,pobi"` |
| 빈 이름 포함 | `"pobi,,woni"`, `"pobi, ,woni"` |
| 시도 횟수 없음 | `""`, `null` |
| 시도 횟수가 숫자 아님 | `"abc"`, `"1a"` |
| 시도 횟수가 0 이하 | `"0"`, `"-1"` |

### ✅ 허용되는 입력
정상적으로 처리되는 입력 예시

| 입력 유형 | 자동차 이름 예시 | 시도 횟수 예시 |
|---------|---------------|-------------|
| 최소 구성 | `"pobi"` | `"1"` |
| 일반적인 경우 | `"pobi,woni,jun"` | `"5"` |
| 5자 이름 | `"abcde,fghij"` | `"10"` |
| 공백 포함 (trim 처리) | `"pobi, woni, jun"` | `" 3 "` |

## 🏗️ 아키텍처

### 클래스 다이어그램
```
┌──────────────┐
│ Application  │ 프로그램 진입점
└──────┬───────┘
       │
       ▼
┌──────────────────┐
│ RacingController │ 게임 흐름 제어
└──────┬───────────┘
       │
       ├──────────┬──────────┬────────────┐
       ▼          ▼          ▼            ▼
  InputView  OutputView    Cars      TryCount
                            │
                            ▼
                           Car
                            │
                            ▼
                      MoveStrategy
```

### 📦 클래스별 책임

| 클래스 | 핵심 책임 | 주요 기능 |
|--------|----------|----------|
| **Application** | 프로그램 실행 | • 의존성 생성 및 주입 |
| **RacingController** | 게임 흐름 제어 | • 입력/출력 조율<br>• 경주 진행 관리 |
| **InputView** | 입력 담당 | • 자동차 이름 입력<br>• 시도 횟수 입력 |
| **OutputView** | 출력 담당 | • 라운드별 상태 출력<br>• 우승자 발표 |
| **Cars** | 자동차 컬렉션 관리 | • 여러 자동차 생성 및 검증<br>• 전체 이동 처리<br>• 우승자 찾기 |
| **Car** | 개별 자동차 | • 이름 검증 (5자 이하)<br>• 전진/정지 결정 |
| **TryCount** | 시도 횟수 관리 | • 횟수 검증 (1 이상)<br>• 횟수 감소 및 확인 |
| **CarStatus** | DTO | • 자동차 상태 전달 (View용) |
| **MoveStrategy** | 전진 전략 | • 무작위 값 생성 (0~9)<br>• 테스트를 위한 추상화 |
| **CarNamesParser** | 이름 파싱 | • 쉼표로 분리<br>• 공백 제거 |

### 🔄 실행 흐름
```
1. Application
   - 의존성 생성 (InputView, OutputView, MoveStrategy)
   - RacingController 실행
              ↓
2. RacingController - 입력 단계
   - InputView: 자동차 이름 입력 → "pobi,woni,jun"
   - CarNamesParser: 파싱 → ["pobi", "woni", "jun"]
   - Cars 생성 (검증 포함)
   - InputView: 시도 횟수 입력 → "5"
   - TryCount 생성 (검증 포함)
              ↓
3. RacingController - 경주 진행
   - OutputView: "실행 결과" 출력
   - 5번 반복:
     ① Cars: 전체 자동차 이동
        → 각 Car: 무작위 값 받아 전진 여부 결정
     ② Cars: 현재 상태를 CarStatus 리스트로 변환
     ③ OutputView: 라운드 결과 출력
              ↓
4. RacingController - 우승자 발표
   - Cars: 최장 거리 찾아서 우승자 이름 리스트 반환
   - OutputView: "최종 우승자 : pobi, woni" 출력
```
