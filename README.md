# 자동차 경주
## 기능 요구 사항
- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈춘다
- 각 자동차에 이름을 부여하고, 전진할 때 이름과 함께 출력한다
- 자동차 이름은 쉼표(,)를 기준으로 구분하며 5자 이하만 가능하다
- 전진 조건: 0~9 사이 무작위 값이 4 이상일 경우
- 경주 완료 후 우승자를 출력한다 (우승자는 한 명 이상일 수 있음)
- 잘못된 입력 시 IllegalArgumentException 발생 후 종료

## 구현할 기능 목록

### 입력
- [x] Console.readLine()을 사용하여 자동차 이름을 입력받는다
- [x] Console.readLine()을 사용하여 시도할 횟수를 입력받는다

### 자동차 이름 검증
- [x] 자동차 이름이 빈 문자열인지 검증한다
- [x] 자동차 이름이 5자를 초과하는지 검증한다
- [x] 자동차 이름에 중복이 있는지 검증한다
- [x] 쉼표로 구분된 자동차 이름을 분리한다
- [x] 자동차가 최소 1대 이상인지 검증한다

### 시도 횟수 검증
- [x] 시도 횟수가 숫자인지 검증한다
- [x] 시도 횟수가 1 이상인지 검증한다

### 자동차 생성 및 관리
- [x] 자동차 이름으로 Car 객체를 생성한다
- [x] Car는 이름과 위치(position)를 가진다
- [x] Car는 초기 위치를 0으로 설정한다
- [x] Cars(일급 컬렉션)로 여러 자동차를 관리한다

### 경주 진행
- [x] Randoms.pickNumberInRange(0, 9)로 무작위 값을 생성한다
- [x] 무작위 값이 4 이상이면 자동차를 전진시킨다
- [x] 무작위 값이 4 미만이면 자동차를 멈춘다
- [x] 한 라운드마다 모든 자동차가 이동을 시도한다
- [x] 지정된 횟수만큼 라운드를 반복한다

### 출력
- [x] 각 라운드마다 실행 결과를 출력한다
- [x] 자동차 이름과 위치를 "{이름} : {-의 개수}" 형식으로 출력한다
- [x] 위치는 "-" 문자로 표현한다 (위치가 3이면 "---")
- [x] 라운드 사이에 빈 줄을 출력한다

### 우승자 판단
- [x] 모든 자동차 중 최대 위치를 찾는다
- [x] 최대 위치와 같은 위치에 있는 자동차들을 우승자로 선정한다
- [x] 우승자가 여러 명인 경우 쉼표(,)로 구분하여 출력한다
- [x] "최종 우승자 : {우승자}" 형식으로 출력한다

### 예외 처리
다음의 경우 IllegalArgumentException을 발생시키고 애플리케이션을 종료한다:

### 자동차 이름 입력
- [x] 자동차 이름이 빈 문자열인 경우
  - 예: "", ",pobi", "pobi,", "pobi,,woni"
- [x] 자동차 이름이 5자를 초과하는 경우
  - 예: "polarbear,crong"
- [x] 자동차 이름에 중복이 있는 경우
  - 예: "pobi,pobi", "pobi,crong,pobi"
- [x] 자동차가 1대 미만인 경우
  - 예: ""

### 시도 횟수 입력
- [x] 시도 횟수가 숫자가 아닌 경우
  - 예: "abc", "1a", "1.5"
- [x] 시도 횟수가 1 미만인 경우
  - 예: "0", "-1"

### 기타 고려 사항
- 자동차 이름 입력 시 공백은 허용하지 않는다
  - 예: "pobi, crong" -> 잘못된 입력 (공백 포함)
- 출력 메시지는 정확히 요구사항과 일치해야 한다
- 무작위 값 생성을 위해 camp.nextstep.edu.missionutils.Randoms 사용
- 사용자 입력을 위해 camp.nextstep.edu.missionutils.Console 사용
